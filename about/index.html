About this project

A bilingual email notification system for Ivanti Neurons for ITSM, built by Asem Zaidan for TjDeeD Technology.

Why this exists

Most ITSM notification emails are plain-text or minimally styled, and rarely support more than one language. This project treats them as a real product surface instead — every status a ticket can be in, across every module Ivanti Neurons for ITSM ships with, gets a purpose-built, bilingual (English / Arabic) HTML email that looks like it belongs to the same design system, so customers see a consistent, professional communication experience from first contact to final closure.

What's inside

60 templates across 11 modules — Incident, Service Request, Approval, Escalation, Task Management, Asset Management, Knowledge Management, Problem Management, Maintenance Operations, Feedback, and Employee — organized under designs. A design is a complete visual system covering every module; Spectrum, the first design, is live today, with a second design planned as a sibling covering the same ground with a different visual language.

Every template is self-contained, table-based HTML with no external stylesheets and no build step — paste it directly into Ivanti's notification editor. See the page for exactly how.

Who built it

Asem Zaidan designed and built this library — from the visual system and the bilingual RTL layout conventions, to every individual template and this site itself.

Questions, ideas, or want a new module covered? Open an issue on GitHub.
